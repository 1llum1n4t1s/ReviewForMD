SUPPORTED SITES

サイトごとに、
出すボタンを変える。

対応サイトと出力

GitHub
PR のタイトル・本文・全レビューコメントを Markdown で保存 / コピー
Azure DevOps
PR を Markdown で保存 / コピー。PR 一覧からも直接ダウンロード
AWS CodeCommit
PR を Markdown で取得
SharePoint
Teams 会議録画の字幕を VTT でダウンロード
Microsoft Teams
チャット履歴を Markdown で取得

ポップアップは今いるサイトを判定し、そのサイトで使えるボタンだけを自動で出し分けます。

01

対象のページを開く

PR ページ、PR 一覧、SharePoint の録画ページ、Teams のチャットなど、取得したい画面を開きます。

02

アイコンをクリック

ポップアップがサイトを判定し、そのページで使えるボタンを表示します。

03

ダウンロードかコピー

.md / .vtt ファイルとして保存するか、クリップボードへコピーします。

FEATURES

一覧からも、
開かずに取れる。

PR 一覧ページでは各行にダウンロードボタンが並びます。レビュー対象をまとめて手元に落としてから、腰を据えて読めます。

  • PR 一覧から開かずに直接ダウンロード
  • レビューコメントを漏らさず取得
  • Markdown コピーとファイル保存の両対応

DESIGN PRINCIPLES

CONTEXTUAL

サイトを判定して出し分け

今いるページで使える操作だけを見せ、迷わせません。

COMPLETE

取りこぼさない

折りたたまれたコメントも含めて、レビュー全体を 1 ファイルにまとめます。

LOCAL

手元に落とすだけ

取得した内容は端末に保存され、外部サーバーへは送信しません。
