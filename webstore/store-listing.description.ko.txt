여러 사이트의 정보를 Markdown / VTT 파일로 다운로드하는 Chrome 확장 프로그램입니다.
GitHub, Azure DevOps, AWS CodeCommit의 PR 리뷰, SharePoint Stream의 Teams 회의 녹화 자막(VTT),
그리고 Microsoft Teams의 채팅 기록까지 한 번의 클릭으로 내 컴퓨터에 저장할 수 있습니다.

【할 수 있는 일】

모든 작업은 도구 모음의 아이콘을 클릭해 여는 팝업에서 합니다.
팝업은 현재 사이트를 판별하여 그 사이트에 맞는 버튼을 자동으로 표시합니다.

▼ Markdown으로 다운로드 / 복사 (PR 리뷰)
GitHub / Azure DevOps / AWS CodeCommit의 PR 페이지에서 아이콘을 클릭하면 팝업에
"MD로 다운로드"와 "MD 복사"가 나타납니다. 제목, 본문, 모든 리뷰 댓글을
하나의 .md 파일로 저장하거나 클립보드에 복사할 수 있습니다.

▼ PR 목록 페이지에서도 바로 다운로드
GitHub / Azure DevOps의 PR 목록 페이지에서는 각 행에 다운로드 버튼이 표시되어, PR을 열지 않고도 바로 가져올 수 있습니다.

▼ 리뷰 댓글을 빠짐없이 가져오기
작성자 이름, 일시, 대상 파일 경로, 변경 내용 코드(diff)와 함께 가져옵니다.
인라인 댓글, 파일 단위 댓글, 전체 댓글을 모두 지원합니다.
Azure DevOps에서는 DOM에서 가져올 수 없는 경우 REST API로 자동 전환합니다.

▼ GitHub / Azure DevOps / AWS CodeCommit 지원
・GitHub(github.com)
・Azure DevOps(dev.azure.com / *.visualstudio.com)
・사용자 지정 도메인의 Azure DevOps(팝업의 "이 사이트에서 동작 허용"에서 해당 사이트만 허용하여 사용합니다)
・AWS CodeCommit(AWS Management Console의 PR 상세 페이지. 상세 페이지 전용)
SPA(싱글 페이지 애플리케이션)의 페이지 이동도 따라갑니다.

▼ SharePoint Stream(Teams 회의 녹화) 지원
회의 녹화 페이지에서 아이콘을 클릭하면 팝업에 "VTT로 다운로드"와 "VTT 복사"가 나타납니다.
스크립트(자막)를 .vtt로 저장하거나 복사할 수 있어 회의록 초안을 만들 때 편리합니다.
스크립트가 없는 녹화에서는 사용할 수 없습니다.

▼ Microsoft Teams 채팅 지원
Teams(teams.microsoft.com / teams.live.com / teams.cloud.microsoft)의 채팅·채널에서
아이콘을 클릭하면 팝업에 다음 버튼이 나타납니다.
・"MD로 다운로드" "MD 복사": 자동 스크롤로 지정한 시작 월부터 현재까지를 수집하여 보낸 사람, 일시, 본문,
  반응, 첨부 링크를 하나의 .md 파일로 저장하거나 복사합니다.
・수집 시작 월은 이번 달 / 지난달부터 / 2개월 전부터 / 3개월 전부터 중에서 선택할 수 있습니다. 기록이 짧은 경우에도 가져올 수 있는 만큼 저장합니다.
・수집하는 동안 페이지 오른쪽 아래에 진행 상황 패널이 표시됩니다. "여기까지 저장"을 누르면 가져온 분량만 저장하고, "취소"를 누르면 저장하지 않고 종료합니다.
  수집은 페이지에서 계속되므로 팝업을 닫아도 괜찮습니다.
・저장 파일 이름은 "채팅 이름_yyyyMMdd.md"입니다. 수집 한도에 도달한 경우에는 중간까지만 저장되었음을 표시합니다.

【이런 상황에서 유용합니다】
・코드 리뷰 기록을 팀과 공유하고 싶을 때
・PR 내용을 문서나 회의록에 옮기고 싶을 때
・리뷰 회고 자료를 만들고 싶을 때
・PR을 열지 않고 목록에서 Markdown 파일로 저장하고 싶을 때
・Teams 회의 내용을 자막 데이터로 회의록으로 정리하고 싶을 때
・Teams 채팅 기록을 백업이나 기록으로 남기고 싶을 때

【사용 방법】
1. Chrome 웹 스토어에서 설치
2. 지원하는 페이지(GitHub / Azure DevOps / AWS CodeCommit의 PR, SharePoint Stream의 회의 녹화, Microsoft Teams의
   채팅·채널)를 엽니다
3. 도구 모음의 확장 프로그램 아이콘 클릭 → 팝업에 해당 사이트용 버튼이 표시됩니다
   - PR: "MD로 다운로드" "MD 복사"
   - SharePoint 회의 녹화: "VTT로 다운로드" "VTT 복사"
   - Teams 채팅: "MD로 다운로드" "MD 복사"
   ※ GitHub / Azure DevOps의 PR 목록 페이지에서는 각 행의 다운로드 버튼으로도 바로 저장할 수 있습니다
4. 버튼 클릭 → .md / .vtt 파일이 저장(또는 복사)됩니다

문제 보고나 문의는 팝업 하단의 "문의하기"에서 보낼 수 있습니다.

【개인정보 보호】
・PR, 자막, 채팅의 가져오기와 파일 생성은 브라우저 안에서 처리합니다
・사용자가 선택 사항인 문의 양식을 제출했을 때만, 입력한 이메일 주소, 선택 입력한 이름, 문의 내용, 확인 코드 등을 Kagayoi Support로 전송합니다
・광고, 분석, 원격 측정 목적의 수집이나 전송은 하지 않습니다
・PR 페이지 / SharePoint Stream / Teams 페이지의 DOM과 공식 API를 읽고,
  클립보드에 쓰고 파일을 다운로드하는 작업만 합니다
・Teams 첨부 파일은 화면에 표시된 링크만 기록하며 파일 자체는 다운로드하지 않습니다
・모든 코드는 확장 프로그램 패키지 안에 포함되어 있습니다
